Dousha for Windows — 按住说话，松开上屏
========================================

【开始使用】
1. 把整个 Dousha 文件夹放到任意位置（不要只拷 exe，旁边的 DLL 都需要）。
2. 双击 dousha-win.exe —— 右下角托盘会出现一个图标，没有别的窗口，这是正常的。
   只双击一次！重复双击不会多开（有单实例保护），但也没有必要。
3. 把光标点进任何输入框（微信、浏览器、Word 都行），按住【右 Ctrl】说话，
   屏幕底部会浮出一个小条实时显示识别结果；松开按键，文字自动打进输入框。

【换按键】
配置文件在：C:\Users\你的用户名\AppData\Local\Dousha\config.json
（资源管理器地址栏粘贴 %LOCALAPPDATA%\Dousha 直达）

用记事本打开，把 "hotkey" 改成下面任意一个，保存后重启 Dousha：
  rightctrl  leftctrl  rightshift  leftshift  rightalt  leftalt
  capslock  f8  f9  f10  scrolllock  pause

"swallowHotkey": true 表示按住期间这个键不会传给别的程序（推荐保持 true）。

【没反应？按顺序检查】
1. 托盘有图标吗？没有就是没启动成功。
2. 说话时底部小条出现了但一直没字 / 提示「没听到声音」：
   九成是【默认麦克风】不对。右键任务栏喇叭 → 声音设置 → 输入，
   选你真正的麦克风。特别注意：装过 Steam 的电脑经常被默认成
   "Steam Streaming Microphone"，那是个没有声音的虚拟设备。
3. 系统设置 → 隐私和安全性 → 麦克风：最上面的总开关和
   「允许桌面应用访问麦克风」都要打开（Dousha 不会出现在应用列表里，
   桌面程序走的是总开关，这是正常的）。
4. 还不行的话，命令行运行自检：
     dousha-win.exe --doctor
   它会逐项检查网络、凭证、识别服务，并告诉你哪一步挂了。
5. 日志在 %LOCALAPPDATA%\Dousha\Logs\dousha.log，发给开发者就能定位。

【退出】
右键托盘图标 → 退出。
